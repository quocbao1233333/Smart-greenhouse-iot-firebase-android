SMART GREENHOUSE DASHBOARD

Cách chạy trên VS Code:
1. Mở thư mục SmartGreenhouseDashboard bằng VS Code.
2. Cài extension Live Server nếu chưa có.
3. Chuột phải index.html -> Open with Live Server.

Cấu trúc Firebase RTDB cần có:
greenhouse/hanoi/sensors/temperature
greenhouse/hanoi/sensors/humidity
greenhouse/hanoi/sensors/soilMoisture
greenhouse/hanoi/sensors/light
greenhouse/hanoi/sensors/co2
greenhouse/hanoi/sensors/waterLevel

greenhouse/hanoi/devices/growLight
greenhouse/hanoi/devices/fan
greenhouse/hanoi/devices/waterPump
greenhouse/hanoi/devices/heater

Các khu vực khác thay hanoi bằng: gialai, hochiminh, camau.

Giá trị thiết bị nên là 0/1 hoặc OFF/ON.
